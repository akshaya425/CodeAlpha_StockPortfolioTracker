# CodeAlpha Stock Portfolio Tracker

## Project Overview
A simple Python application that calculates the total investment value of a stock portfolio using manually defined stock prices.

## Features
- Displays available stock symbols and their prices
- Accepts stock names and quantities from the user
- Calculates the value of each stock holding
- Displays the total investment value
- Optionally saves the portfolio summary to a text file
- Handles invalid stock names and quantities

## Technologies Used
- Python
- Dictionaries
- Loops and conditional statements
- User input and output
- Basic arithmetic
- File handling

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python stock_tracker.py`

## Note
The stock prices are predefined sample values and are not live market prices.
